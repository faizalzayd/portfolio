★ Research Project

Quantum-Safe MIME Email System

A complete encrypted email client built to survive quantum adversaries. Wraps a C binary implementing McEliece KEM with a Python application layer, creating a three-tier encryption model: McEliece KEM for key exchange, AES-256-CBC for message transport, and AES-256-CBC for storage at rest — all delivered via standard MIME format. The C/Python bridge required resolving header redefinition issues and a critical redundancy parameter bug in the decoder.
